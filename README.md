# CS6220 Homework 3

Scaffold for k-nearest neighbors, the perceptron, and a single neuron, plus a demo notebook that records gradient flow through a network trained on MNIST.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name cs6220_HW3 --display-name "cs6220_HW3"
jupyter lab
```

Open `homework_3.ipynb` and `demo_gradient_flow_mnist.ipynb`, select the `cs6220_HW3` kernel, and choose Run All.
